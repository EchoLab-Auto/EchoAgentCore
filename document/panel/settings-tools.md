# 设置 · 工具

> **定位**：工具工作台——按包分组的清单与状态标记、详情四分区（能力说明 / 被谁使用 / 所属包 / 参数 Schema），以及启停的两层语义（全局开关 × 各智能体白名单）。工作台骨架见[设置视图](./settings.md)「资源工作区通用契约」。读者：维护工具相关界面的开发者；相关：[工具系统](../plugins/tools.md)、[插件化设计](../plugins/plugins.md)（包与门控）、[设置 · 插件](./settings-plugins.md)（包归属与交叉跳转）。

## 列表与分组

与技能工作台同构（筛选栏 + 双行行卡 + 分栏可拖 + 详情分区），差异点：

- **按包分组**（默认）：工具按 `package` 归组，组名取 `capabilities.ts::PACKAGE_DISPLAY_NAMES`（如「内置工具集」「QQ 实例包」「Subagent 委派」「工作区会话」——注意 `instance.qq` 的显示名是「QQ 实例包」），与智能体能力勾选区同构
- **原「按分类」已退化**：内置工具的 `category` 一律 `builtin`，全归一组；只有进程外插件贡献的工具带 `category = plugin`；`builtin` 类工具归入「内置工具」组
- **行卡主行** = 状态点 + 名称 + `包已禁用` 标记 + hover 快速启停；**次行** = 描述（工具无触发词）
- **副标题**：`共 N 项 · K 个包 · D 已禁用`

## 详情分区

| 分区 | 内容 |
| --- | --- |
| ① 能力说明 | 启停是全局开关；启用时仍受各智能体白/黑名单约束——两层叠加 |
| ② 被谁使用 | 按 `disabled_tools` / `enabled_tools` 反查四态 |
| ③ 所属包 | 包 id + 「在「插件」中查看 →」跳转（→ [设置 · 插件](./settings-plugins.md)） |
| ④ 参数 Schema | **参数表**：参数 / 类型 / 必填（warning tag）/ 说明；右上角切 JSON 原文 + 复制；schema 无 `properties` 时回落 JSON 原文 |

## 启停语义

`ToggleTool` 是**全局**开关：禁用后模型不可见（列表行内 hover 亦有快速开关）。它与智能体级白名单是两层叠加——工具在此启用，只代表「对所有智能体可见的候选」，某个智能体仍可通过 `enabled_tools` 非空（白名单收起）或 `disabled_tools` 把它排除；反之工具被全局禁用时，任何智能体的勾选都不再生效。包的维度更高一层：所属包插件被禁用时，包内全部工具对所有智能体不可见（组头给出「包已禁用」提示）。
