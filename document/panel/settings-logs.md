# 设置 · 日志与系统

> **定位**：「日志」分类的运行日志查看器（Core / Panel / SSH 上游三来源）与「系统」分类的自更新入口。菜单与切换语义见[设置视图](./settings.md)。读者：维护日志与自更新界面的开发者；相关：[部署与自更新](../ops/deploy.md)（更新服务与流程）、[Panel 前端](./panel.md)（日志 API 与 SSH 隧道）。

## 日志查看器

整页查看器（`LogView.vue`）：

- **来源分段**：Core / Panel 切换（默认 Core），拉取 `/api/logs/{core,panel}?lines=100` 原文显示（max-height 65vh 内滚动）
- **刷新**：自动刷新默认开（**5s** 间隔），可切手动，另有手动「刷新」按钮；切换来源或自动开关立即重载并重启定时器；HTTP 错误显示状态码
- **客户端过滤**：级别分段（全部 / INFO+ / WARN+ / ERROR，按行内 `INFO`/`WARN`/`ERROR` 词元判定；判不出级别的续行保留）与关键字输入（大小写不敏感子串）叠加生效，右上角显示 `命中 / 总行数`；无命中显示「（没有匹配的行）」而不是空白。过滤全在前端做，后端接口不变
- **跟随最新**：默认滚到底部；关掉后内容更新不再抢滚动位置（读历史日志时不会被 5s 刷新甩回底部）
- **卸载语义**：**切换分类即卸载**——定时器随卸载清理，切回时重新挂载拉取

## SSH 上游日志

存在 SSH 接入的上游时，Core 视图追加「本机 / 各 SSH 上游」选择器——选中 SSH 上游则请求带 `?core=<上游名>`，Panel 后端经隧道在远端执行 journalctl（两代单元名 `-fixed` 与现役**合并**取最新 N 行；失败给出可操作提示）；选中上游被删除 / 改直连自动回退「本机」。
