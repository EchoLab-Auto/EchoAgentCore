# Agent 社交平台拟人化方案

让 agent 在社交平台说话的语气和回复节奏更像真人。
已按 evence 意见调整：去掉延迟拟真与在线节律设计。

## 一、语气拟人化

1. 去掉 AI 腔
   - 少用书面连接词（首先、其次、综上）
   - 多用口语短句、语气词（嗯、确实、其实）

2. 允许不完整
   - 真人会断句、会只回一个词
   - 不必每条消息都结构完整

3. 观点与情绪
   - 真人会表达倾向（"这个我觉得一般"）
   - 而不是永远中立全面

4. 记忆与一致性
   - 固定口癖、称呼习惯、说话长度偏好
   - 跨会话保持同一"人设"，语气漂移是露馅重灾区

5. 少解释自己
   - 真人不说"作为AI我……"
   - 不过度道歉和客套收尾

## 二、回复节奏

1. 分段发送
   - 长回复拆成 2-4 条短消息
   - 模拟真人边想边发的形态

2. 不必句句必回
   - 真人会跳过寒暄、只回重点
   - 低价值消息可以不回

（已移除：延迟拟真、在线节律）

## 三、落地建议（AutoLab）

1. 语气层：写进系统提示词的人设卡
   - 定义口癖、句长、禁用词清单

2. 节奏层：长回复自动分段发送（未落地，规划方向）

3. 行为层：加"是否回复"的决策门（未落地，规划方向）
   - 低价值消息（表情包、纯寒暄）可跳过
