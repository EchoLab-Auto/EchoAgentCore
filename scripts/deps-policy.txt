# echo-* 依赖白名单 —— 依赖方向的**单一真值来源**
#
# 两处门禁共读本文件，避免「CI 绿但实际越界」：
#   - `scripts/check-deps.sh`（CI 的 dependency-direction-lint job，纯 bash）
#   - `source/core/tests/plugin_dependency_direction.rs`（cargo test）
#
# 格式：`<source/ 下相对目录> <允许的 echo-* 依赖...>`（空白分隔）
#   - 空行与 `#` 注释被忽略；
#   - 每行是**完整白名单**（不是增量）：列出的依赖之外一律违规；
#   - `[dependencies]` 与 `[dev-dependencies]` 都算。
#
# 纪律：
#   1. **新增 crate 必须登记**——两处门禁都会报「未登记」并失败（fail-closed），
#      忘登记不会静默放行；
#   2. **`echo-agent`（业务 crate）只允许出现在 `core`**（组合根）；
#      `echo-agent-core` 是二进制名，不应被任何 crate 依赖；
#   3. 方向只向下：定义层 → 机制层 → 插件层 → 宿主 → 组合根。想在插件里用
#      框架能力，走服务键 / `HostCall` / trait 注入，而不是 `use echo_agent::…`。
#
# 分层依据见 document/overview/architecture.md；Phase 3 外迁记录见
# document/design/decoupling-plan.md。
