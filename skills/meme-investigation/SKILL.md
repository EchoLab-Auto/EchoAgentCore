# 找梗与考据的工作方法

遇到"这是什么梗/这影射什么/出处是什么"类任务时按此执行。

## 1. 穷尽显式线索，先查再推理

- 把画面/文本里所有专有名词、场景元素（招牌、地名、人名、日期、物品）逐个列出当查询词。
- 每个元素先单独搜一遍有没有对应实时事件，再开始理解剧情。
- 任何"看似只是背景"的元素都可能是梗的锚点，禁止默认其为无意义装饰。

## 2. 语言跟随事件属地

- 中文搜不到不等于不存在。事件发生在哪，就用哪的本土搜索和语言：
  - 韩网 → Naver（search.naver.com）
  - 日网 → Yahoo 日本 / Google 日本
  - 国际 → 英文关键词
- 不要用中文去硬搜国际事件，百度百科式命中等于没搜。

## 3. 分层验证映射

- 梗的结构通常是"现实事件 → 作品角色/场景"的映射。
- 找到候选事件后必须能对上：谁对应谁、哪个细节对应哪个细节。
- 对不上就是还没找到真正的事件，继续找，不要强行解释。

## 4. 区分内容分析和语境分析

- 内容（台词、画面、剧情）：靠下载、ASR、视觉模型等工具分析。
- 语境（为什么是这个题材、为什么现在发）：只能靠外部信息检索。
- 顺序：先语境后内容。语境没搞清时做内容分析是浪费时间。

## 5. 失败时扩大查询面而非加深分析

- 一个方向搜不到，别在原方向加深度（换 ASR 模型、换视觉模型之类）。
- 加宽度：换语言、换平台、换同义词、换视角（从事件侧反推作品侧）。
- 同一关键词撞两次百科/无关结果就换语种，不要第三次。

## 反模式（本次教训）

- 过早收敛：搜两次没结果就换方向看视频，把核心线索当背景板。
- 关键词太死：单一语言直搜，撞上百科词条还以为搜过了。
- 工具用偏：花大力气分析画面内容，忽略了真正的线索在外部事件里。
- 讽刺结构理解浅一层：角色不只是参演，可能是组织者——映射要追到功能位。
