# 写公式的正确格式（KaTeX）

会话正文里的公式由 KaTeX 渲染（ui-frame `MarkdownRenderer`，见
`composites/doc/math.ts`）。**渲染器只认下面四种定界符**，写成别的样子
（`\begin{equation}` 裸放、`[math]`、`$$` 只写一半）一律不渲染，用户看到的是
原始 TeX 源码。

先记一句话规则：**句子里的式子用 `$…$` 贴紧内容；需要占一整行的推导用
`$$` 独占一行包起来。**

## 一、四种定界符

| 写法 | 用在哪 | 效果 |
| --- | --- | --- |
| `$…$` | 句子中间 | 行内公式，与正文同一基线 |
| `$$` 独占一行 | 单独成段 | 块级公式，居中、长公式可横向滚动 |
| `\(…\)` | 句子中间 | 行内（LaTeX 习惯）。**句子里 `$` 有歧义时用它** |
| `\[` `\]` 独占一行 | 单独成段 | 块级（LaTeX 习惯） |

同一句里 `$` 出现次数为奇数、或者句子本身在谈钱时，直接用 `\(…\)` 最省事 ——
它不会和美元符号抢解释权。

## 二、行内还是块级

- 变量、单个表达式、带单位的量 → **行内**：`损失从 $0.83$ 降到 $0.32$`。
- 等式、多行推导、求和/积分/矩阵/分段函数 → **块级**。
- 判断口径：这句话读起来需要"停一下看图"吗？需要 → 块级。
- **不要把 `$$` 塞进句子中间**（实测）：`公式 $$a^2$$ 在这里` 会把句子劈成
  「`公式`」+ 公式块 + 裸文本「`在这里`」三截，观感很糟。句中的式子一律用
  `$…$`。

## 三、六条硬规则（每条都实测过，违反了就不渲染）

1. **定界符要贴紧内容，里面首尾不留空格。**
   `$ a + b$`、`$a + b $` 都不认（会被当成普通文本，Dollar 原样显示）。
2. **一条行内公式不能跨行。** 式子长到要换行 → 改块级。
3. **闭合 `$` 后面不要紧跟数字。** `$5$6` 会被判成两笔金额，两个都不渲染。
4. **块级 `$$` 独占一行，前后各留一个空行。** 标准写法：

       $$
       a^2 + b^2 = c^2
       $$

   单行写 `$$a^2+b^2$$` 也认，但一样独占一行。
5. **谈钱写 `\$`。** 正文里的金额请写 `\$199`；一个落单的 `$` 会让同一句里
   靠近它的内容被判成"价格"而失效。
6. **公式里不要出现反引号或中文全角标点**（`，。、；：！？…`）。出现即视为
   "句子里散落的 `$`"，不渲染。

## 四、列表 / 表格 / 引用 / 标题

- **列表项内的块级公式要缩进**到条目内容层（2 空格），否则列表会被公式劈成
  两段（实测：`- 一` + 不缩进的 `$$` + `- 二` → 两个独立的列表）。
- **表格单元格里放行内公式没问题**，但绝对值别写裸 `|`（会切断表格列），用
  `\lvert x \rvert`（或 `\|x\|`）。
- 引用块（`>`）、标题（`##`）、有序/无序列表里都能放行内公式。
- 块级公式在引用块里要每行都带 `>`。

## 五、KaTeX 的支持范围（不是完整 LaTeX）

**能用**：`\frac` `\dfrac` `\sqrt` `\sum` `\prod` `\int` `\lim` `\log`
`\mathbb` `\mathcal` `\operatorname` `\text{中文}` `\tag{1}` `\def`
`\begin{aligned}` `\begin{align}` `\begin{pmatrix}` `\begin{cases}`、
希腊字母命令、`\left(…\right)`。

**不能用 / 有坑**：

| 写法 | 实际结果 | 改成 |
| --- | --- | --- |
| `\ce{H2O}`（化学式，需 mhchem 扩展） | 渲染成**红色** `\ce` | `\mathrm{H_2O}` |
| `\label{…}` / `\ref{…}` / `\eqref{…}` | `\label` 变红色原文；无交叉引用 | 编号手写 `\tag{1}`，正文写「式 (1)」 |
| `\usepackage` `\input` `\includegraphics` TikZ | 全部不支持 | 图用 Markdown 图片语法 |
| `\newcommand{\R}{…}` | 报「已经定义」→ 整条变红 | KaTeX 预置了 `\R \N \Z \Q \C`，换个名字或改用 `\def` |
| 未定义命令（拼错） | **不崩**，但会渲染成红色原文里的一段 | 自检命令拼写 |

真语法错（如 `$\frac{a}{$`）只让**这一条**变红色原文，同段其余内容正常 ——
所以"某条公式是红的"通常是写法问题，不是渲染器坏了。

## 六、中文、单位、符号

- 中文放进 `\text{}`：`$\text{总损失} = 3$`。裸中文虽然能显示，但字距与公式
  字体不一致，读起来像被拉长。
- 单位也用 `\text{}` 并且前面加窄空格 `\,`：`$5\,\text{ms}$`。
- 希腊字母/运算符优先写命令（`\alpha`、`\times`、`\le`），不要直接粘 unicode
  字符 —— 混排时字体不一致。
- 下标里的中文可直接写：`$x_{总}$`。

## 七、写完自检（逐条过一遍，30 秒）

1. `$` 成对了吗？数一遍总数 —— 奇数就是有落单。
2. 每对 `$` 里面首尾没有空格、没有换行？
3. 块级 `$$` 独占行、前后有空行？没有塞在句子中间？
4. 金额都写成 `\$` 了？正文里还有没有裸 `$`？
5. `\begin{…}` 与对应的 `\end{…}` 配对了？花括号、`\left/\right` 都闭合了？
6. 命令名拼对了？（`\frac` `\sqrt` `\sum` `\begin` 最容易漏字母）
7. 需要编号的写了 `\tag{n}`？
8. 中文在 `\text{}` 里、单位前有 `\,`？

## 八、照抄就能用的模板

行内：

    损失从 $L=0.83$ 降到 $L=0.32$，推理延迟 $5\,\text{ms}$。

块级推导（多行对齐，换行写 `\\`）：

    $$
    \begin{aligned}
    \mathcal{L} &= -\frac{1}{N}\sum_{i=1}^{N}\log p_\theta(y_i \mid x_i) \\
    \frac{\partial \mathcal{L}}{\partial \theta} &= 0
    \end{aligned}
    $$

矩阵：

    $$
    A = \begin{pmatrix} a & b \\ c & d \end{pmatrix},\quad
    \lVert x \rVert_2 = \sqrt{\sum_i x_i^2}
    $$

分段函数：

    $$
    f(x) = \begin{cases}
    x^2, & x \ge 0 \\
    -x, & x < 0
    \end{cases}
    $$

带编号：

    $$
    E = mc^2 \tag{1}
    $$

化学式（没有 mhchem，用 `\mathrm`）：

    $\mathrm{H_2O}$、$\mathrm{CO_2}$、$\mathrm{Fe^{3+}}$

## 九、纯文本通道不要用这些定界符

QQ、邮件、终端输出等**不经过 Markdown 渲染**的地方，写 `$…$` 只会把美元符号
和反斜杠原样发给对方。那些通道改用 unicode 近似或纯文字：

- `∑` `∏` `√` `≈` `≤` `≥` `α β γ` `∂` `∫`
- 分式写成 `a/b`，指数写成 `x^2` 或 `x²`
- 需要完整排版就把内容放进面板/文档，别塞进聊天消息

## 十、明明写了却没渲染？按这个顺序查

1. **这条消息走的是 Markdown 吗？** 用户自己发的消息、以及工具输出里的代码块
   都是纯文本，公式不会渲染（用户消息刻意保持纯文本，避免用户输入被 Markdown
   改写）。
2. **是不是还在流式中？** 回答进行中显示的是纯文本，本条回答**结束后**一次性
   渲染成公式 —— 不是坏了。
3. **是首次出现公式吗？** KaTeX 是按需加载的，第一条公式会稍等一个 chunk，
   之后走缓存。
4. **`$` 成对吗？** 见第七节第 1 条。
5. **公式是不是整条变红了？** 那是 KaTeX 报错（命令拼错、`{}` 不配对、
   `\label` 之类），修写法即可，不用怀疑渲染器。
