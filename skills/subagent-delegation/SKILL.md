# 子任务委派与并行化

## 0. 开工前：先扫"可委派块"（硬性习惯）

收到非平凡任务后、第一次动手前，花 30 秒对照下表扫描；命中任一即列入
委派候选，并写进你的执行计划（哪怕最后决定不委派，也要先扫一遍）。

| 信号 | 动作 | 实测依据（2026-09 审计：17 个 turn、634 次工具调用、0 次委派） |
| --- | --- | --- |
| 调查/分析/审计/排障类，预计探查命令 > 5 条 | 探查包整体委派，按线索拆 1-3 个子代理 | 此类 turn 中位 52 步、墙钟 6–12 分钟，估省 40–50% |
| 跨仓库/跨模块改动，且文件零交集 | 按仓库/单元并行委派实现 | 估省 20–35%（两个仓库本就互不阻塞） |
| 文档同步、真实数据离线验证、回归脚本 | 与主线**并行**委派，主线继续集成 | 近乎白赚，且原始输出不污染主上下文 |
| Playwright / 浏览器 / 网络实测 | 委派，只要结论与数字 | 此类 turn 的中间输出全是数值噪声，主线程只需结论 |

委派判断口径：**在隔离上下文里预计跑 ≥2 分钟，且产物可独立验收**。不满足
就别委派——启动与回报开销大于收益。

不要委派：需要当前对话上下文才能回答的问题（子 agent 看不到）、简单一步就
能完成的操作、需要把结果直接发给 QQ 用户的任务（子 agent 不能投递外部平台，
结论由你转述）、两个子任务会改同一个文件/同一接口的。

## 1. 并行的三种手段（按此优先级选择）

1. **spawn_subagent** —— 唯一真并行：立即返回子任务 id，后台执行，完成后以
   `<subagent_event>` 事件回报（新一轮输入）。多个子任务互不阻塞。
2. **单条 bash 内后台批处理** —— I/O 型探测（curl/ss/journalctl/网络测试等）
   互相独立时，一条命令里并发跑完：
   ```bash
   cmd1 >/tmp/p1.log 2>&1 & p1=$!
   cmd2 >/tmp/p2.log 2>&1 & p2=$!
   wait $p1 $p2
   cat /tmp/p1.log /tmp/p2.log
   ```
   3 条各 10s 的探测：串行 30s → 并发约 12s。总时长受工具 timeout 约束。
3. **不要指望"一次响应里发多个 tool_call"提速**：框架对 tool_calls 是逐个
   `await` **串行执行**（内置循环与 echo-loop 皆如此，勿再假设并行）。
   要并行只有上面两条路。

选择：需要隔离上下文/产物是结论 → 子代理；只是本机几条快探测 → bash 批处理。

## 2. 委派 task 模板（自含 + 只要结论）

子 agent 在全新隔离上下文里执行：看不到当前对话、你的推理、此前的工具输出。
task 必须自含全部背景。按模板写：

```text
背景：<项目/仓库绝对路径；目标与当前状态；相关文件或上一步结论>
要做：<精确步骤；能给命令就给命令；可自由探索的范围边界>
约束：只读 / 只改列出的文件；不要动 git；不要反问（没人能答），拿不准
      就按合理假设继续并在结论里注明
产出：结论 + 关键数字 + 文件:行号；≤800 字；不要贴大段原始输出
```

- 结论超长会被截断（保留前 8K 字符）——要求"只回结论"，长清单用文件落盘
  并回路径
- 单层委派：子 agent 没有 spawn_subagent，不能再向下拆分
- 默认超时 600s；预期更久（大规模构建/长验证）显式传 `timeout_secs`

## 3. 实现类任务的并行拆分

按**接口边界**拆，且只拆文件零交集的单元：

1. 先由你冻结共享接口（数据类型、组件 props、模块契约），写进各子任务
   task——接口不定就拆，子 agent 会各自发明不兼容的约定
2. 集成步骤（产物接进宿主文件、测试适配、构建部署、git 提交）天然串行，
   由你完成，不要委派
3. 多子任务改同一文件必然冲突，禁止并行

## 4. 等回报期间不空转

- 委派是异步的：**不要反复查询或重复委派同一任务**；把"等待"用来推进
  非重叠工作（写文档、准备测试、处理部署、检查环境）
- 回报到达后：先抽查关键数字/事实（子 agent 会出错），再向用户转述；
  多个子任务结论冲突时，自己动手复核分歧点
- 子任务结果要作为新的输入事件消耗——若已不需要（任务已被取消/变向），
  明确说明而不是硬凑进回复

## 5. 汇报口径

对用户只报"做了什么 + 结果 + 证据"（如"委派 2 个子代理并行调查，合计
节省约 X 分钟"），不复述子任务内部过程。
